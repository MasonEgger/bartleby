## Observations

- FontAwesome's bundled path is `fontawesome-brands/<name>.svg` but the icon syntax is `fontawesome-brands-<name>` (with "brands" as part of the icon name). The resolution code strips the leading `brands-` from the rest after consuming the `fontawesome-` prefix. Same approach generalises to other FontAwesome variants (regular, solid) if/when added.
- `class="icon-<name>"` is the convention pymdownx.emoji emits when it expands `:name:` references against the configured emoji index. The regex captures every such reference across the rendered HTML.
